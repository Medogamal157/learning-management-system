# Oman School E-Learning Platform — Documentation Package

**Version:** 1.0 | **Prepared:** 19 October 2026 | **Format:** Markdown (`.md`)

These documents record the confirmed business model and the proposed architecture for a teacher-led Oman K–12 e-learning marketplace.

## Confirmed centerpiece

The platform collects course payments, retains an agreed platform commission, grants learning access to the chosen student, and later pays teachers through a controlled, auditable settlement process. It supports student and guardian accounts, independently owned teacher courses, teacher assistants, delegated admin employees, recorded lessons and live sessions.
